# client-orders-1с

# 🧾 Учёт заказов клиентов (1С)

## 📌 Описание
Конфигурация для автоматизации учёта заказов клиентов: оформление заказов, расчёт сумм и анализ продаж.

---

## ⚙️ Функционал
- Справочники: Клиенты, Товары
- Документ: Заказ клиента
- Табличная часть (товары)
- Автоматический расчёт суммы
- Проведение документа
- Регистр накопления: Продажи
- Регистр сведений: Цены
- Отчёт: Продажи за период

---

## 🧠 Использовано
- Платформа 1С:Предприятие 8.3
- Управляемые формы
- Регистр накопления
- Регистр сведений
- Запросы

3. Запустить в режиме предприятия
